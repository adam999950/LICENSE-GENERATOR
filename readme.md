# License Generator

A simple tool to generate open-source licenses such as MIT, GPL, and Apache for your projects. The app is built using Python and Tkinter for the GUI.

## Features

- **Generate licenses**: Choose from a list of pre-defined licenses (MIT, GPL, Apache).
- **Customizable author name**: Enter your name or organization to personalize the license.
- **Save to file**: After generating the license, you can save it to a `.txt` file.
- **Cross-platform**: The app works on any platform that supports Python and Tkinter.

## Supported Licenses

- **MIT License**: A permissive license that allows you to freely use, modify, and distribute the software.
- **GPL License**: A copyleft license that requires modified versions to be open-source as well.
- **Apache License**: A permissive license similar to MIT but with an added provision for patents.

## Requirements

- **Python 3.x**: The tool is built using Python and Tkinter.
- **Tkinter**: Tkinter comes pre-installed with Python, but if you don't have it, you can install it using `pip`.
